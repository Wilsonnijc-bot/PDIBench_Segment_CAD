Six-link PDI does not reliably detect robot deformation.

We segment six robot links, run PDI on each link, and compare the scores with human labels.

Method

Segment the robot, then score each link.

Six masks. Six PDI scores.

DINOv2 and SAM3 segment links 2–7. PDI runs separately on each link, and the scores are compared with human deformation labels.

Correlation with human labels

Large scores would indicate agreement. Instead, every deformation correlation stays close to zero or moves in the wrong direction.

Why it fails

Three main reasons.

1

The rigidity formula misses uniform shape change

A link can shorten while its pairwise ratios remain consistent, producing a low rigidity score.

2

Tracking failure can become a maximum score

When too few points survive, the current fallback can return 1.0 instead of marking the link unavailable.

3

Scale dominates the combined PDI

The raw components are not normalized, so scale variation overwhelms trajectory and rigidity.

Next

Repair the measurement before repeating the correlation study.

1. Mark failed links unavailable

Insufficient masks, tracks, depth, or pairs should return NaN, not 1.0.

2. Measure absolute deformation

Add a score that responds directly to shortening, swelling, and local shape change.

3. Normalize and rerun

Balance the PDI components, rerun COSMOS2.5, then repeat validation.
