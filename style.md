Research Evaluation Atlas — Generalizable Web Style Guide

Use this style for research dashboards, benchmark browsers, evaluation portals, experiment atlases, model-comparison websites, dataset explorers, or technical result viewers.

The goal is clean research software, not a marketing landing page and not a paper replica. The interface should feel credible, calm, quantitative, dense enough for technical users, but still visually polished.

1. Visual Character

Design for these qualities:

Research-first: results, evidence, comparisons, and raw values are primary.

Quietly polished: use soft depth, restrained color, rounded surfaces, and careful spacing.

Information-dense but not cramped: many metrics can appear at once, but hierarchy must remain obvious.

Neutral by default: most of the UI is gray/white; color is reserved for meaning.

Dashboard-like, not enterprise-heavy: avoid oversized sidebars, thick borders, or admin-panel clutter.

Modern scientific tooling: combine a strong hero/introduction with compact analytical components.

Data remains interpretable: never hide metric direction, scale, missingness, or source behind a single decorative score.

A useful shorthand:

Soft research dashboard + evaluation atlas + lightweight scientific explorer.
