Normal patch codebook mathematics and sizes
For each FPS patch j at scale ℓ: fⱼ = centroid_MLP(mean(pᵢ − FPS_centerⱼ) in patchⱼ) + mean(FCGF features in patchⱼ).
qⱼ = fⱼ / ‖fⱼ‖₂.
Nearest normal entry: k* = argmaxₖ(qⱼ · cₖ); similarity s* = qⱼ · cₖ*.
If s* ≥ 0.85: cₖ* ← normalize[(nₖ*cₖ* + s* qⱼ)/(nₖ + s*)]; nₖ* ← nₖ* + 1.
Otherwise add qⱼ as a new normal entry.
These are the actual repository equations. The backbone is frozen pretrained FCGF; the detector's patch MLP is trainable. The native Phase2 loop refreshes the codebook from normal samples only, so final codebook sizes can differ between the two augmentation runs.

Mathematical deformation definitions


Define x = (p − a)·u and r = p − a − xu. The fixed axis and end anchor are fitted once from the same 20 normal observations.


Axial strain: s = (1 − f)L; t = max(x − s, 0).
p′ = p + (α − 1)tu.
Thus x′ = x for x ≤ s, and x′ = s + α(x − s) for x > s; r′ = r.


Shortening α ∈ [0.70, 0.95]; lengthening α ∈ [1.05, 1.30]. Affected fraction f is sampled from [0.40,0.60], [0.60,0.90], or [0.90,1.00]. Cross-sectional thickness is unchanged.


Circular-arc bend: choose unit v perpendicular to u; w = u × v.
s = start_fraction × L; κ = bend_angle_radians / (L − s).
For x > s: t = x − s; θ = κt.
c(t) = a + su + sin(θ)/κ u + (1 − cos(θ))/κ v.
R_w(θ)r = r cos(θ) + (w × r) sin(θ) + w(w·r)(1 − cos(θ)).
p′ = c(t) + R_w(θ)r.
For x ≤ s: p′ = p. For κ = 0: p′ = p.


Bend direction angle is uniform [0,2π); start_fraction ∈ [0,0.5]. Mild distal angles are 5–15°; strong angles 20–45°. Each cross-section receives a rigid rotation, preserving its local geometry. The code evaluates 1−cos(θ) as 2sin²(θ/2) for numerical stability.


Exact correspondence: point i remains point i.
offset_gt,i = p_normal,i − p_anomaly,i.
mask_gt,i = 1 if any coordinate was actually modified; otherwise 0.
Training distribution: 25% shortening + 25% lengthening + 25% mild bending + 25% strong bending.
